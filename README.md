# Producers Direct - Business Analytics MVP

Plataforma Web interactiva ($0 Infraestructura) para el análisis del Fondo Rotatorio y generación de Fichas de Acompañamiento Técnico.

## Arquitectura y Despliegue
- **Frontend Pure HTML/JS/CSS**: Carga estática servida vía GitHub Pages.
- **Procesamiento Cliente (Browser-side)**: Cálculo PCA e ingesta Excel $0 servidor usando SheetJS y Chart.js.
- **Alineación CRISP-DM**: Fases integradas desde el entendimiento de negocio hasta la auditoría de datos.
